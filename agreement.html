Reference versus algorithm
Agreement between every pair of annotation pipelines that differs in exactly one choice, across the eight held-out cohorts.
  • The comparison
Code 
pairs = transpose(pairs_raw)
sel   = pairs.filter(d => d.concept === concept && d.scatlasvae_head === head)
med   = a => a.length ? d3.median(a) : NaN
fmt3  = d3.format(".3f")

// Per-concept dominance, computed here rather than read from a table, so the head control
// actually changes it.
ranked = {
  const out = [];
  for (const c of new Set(pairs.map(d => d.concept))) {
    const rows = pairs.filter(d => d.concept === c && d.scatlasvae_head === head);
    const alg = med(rows.filter(d => d.pairtype === "swap_algorithm").map(d => d.containment));
    const ref = med(rows.filter(d => d.pairtype === "swap_reference").map(d => d.containment));
    if (Number.isFinite(alg) && Number.isFinite(ref) && ref > 0)
      out.push({concept: c, alg, ref, ratio: alg / ref});
  }
  return out.sort((a, b) => b.ratio - a.ratio);
}

byCohort = {
  const out = [];
  for (const co of new Set(sel.map(d => d.cohort))) {
    const rows = sel.filter(d => d.cohort === co);
    out.push({
      cohort: co,
      alg: med(rows.filter(d => d.pairtype === "swap_algorithm").map(d => d.containment)),
      ref: med(rows.filter(d => d.pairtype === "swap_reference").map(d => d.containment))
    });
  }
  return out.filter(d => Number.isFinite(d.alg) && Number.isFinite(d.ref))
            .sort((a, b) => a.alg - b.alg);
}

PT = d => d === "swap_algorithm" ? "same reference, other algorithm"
                                 : "same algorithm, other reference"

Code 
md`A rare state can look discordant simply because two small sets rarely intersect. Lift divides the
observed overlap by what two sets of the same sizes would share at random, so the red line at 1 is
chance. Reference-swap agreement sitting above that line means the two calls are related and still
largely disjoint, which is a different claim from the calls being unrelated.`

Sixteen annotation pipelines run on the same cells: six label-transfer algorithms crossed with three reference atlases. Every pair differing in exactly one of those two choices is scored here, across all eight held-out cohorts.

md`Agreement is measured as containment: the overlap divided by the smaller of the two sets.

The manuscript figure uses the \`knn\` head. The \`softmax\` head is scAtlasVAE's parametric
classifier, which does not reproduce itself across random seeds; it is available here as a control.

Pairs that change both the reference and the algorithm are excluded, because the loss cannot be
attributed to either one.`
